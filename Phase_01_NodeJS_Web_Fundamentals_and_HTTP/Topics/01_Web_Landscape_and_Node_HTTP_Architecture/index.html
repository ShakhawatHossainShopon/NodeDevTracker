ফেজ ০১: Node.js ওয়েব ফান্ডামেন্টালস টপিক ০১

আধুনিক Node.js ওয়েব ল্যান্ডস্কেপ ও নেটিভ HTTP আর্কিটেকচার

সহজ বাংলায় বুঝুন: Node.js কীভাবে ওয়েব ব্যাকএন্ড চালায়, ব্রাউজার থেকে রিকোয়েস্ট এলে সার্ভারে কী ঘটে এবং Express.js এর আসল ভিত্তি কী।

🌍 ১. ওয়েব ব্যাকএন্ডে Node.js কেন এত জনপ্রিয়?

সহজ ভাষায় বলতে গেলে, আগেকার দিনের অনেক ট্র্যাডিশনাল ওয়েব সার্ভার (যেমন ক্লাসিক Apache/PHP বা Java) প্রতিটি নতুন ইউজারের রিকোয়েস্টের জন্য কম্পিউটারের একটা করে আস্ত Thread (থ্রেড) বুক করে রাখত। এক হাজার ইউজার একসাথে এলে এক হাজার থ্রেড চালু রাখতে প্রচুর RAM শেষ হয়ে সার্ভার স্লো বা ক্র্যাশ হয়ে যেত।

Node.js এই ধারণাই পাল্টে দিয়েছে:

  • Node.js চলে সিঙ্গেল থ্রেড (Single Thread) কিন্তু Non-blocking I/O আর্কিটেকচারে।
  • রেস্তোরাঁর একজন দক্ষ ওয়েটারের মতো—অর্ডার নিয়ে রান্নাঘরে পাঠিয়ে দেয়, তারপর অন্য কাস্টমারের অর্ডার নিতে চলে যায়। রান্নার জন্য ঠায় দাঁড়িয়ে থাকে না!
  • ফলে খুব কম মেমোরি (RAM) খরচ করেই হাজার হাজার ইউজারকে একসাথে হ্যান্ডেল করতে পারে।

🎯 ওয়েবে Node.js কোথায় সেরা?

  • RESTful ও GraphQL JSON API তৈরিতে
  • রিয়েল-টাইম চ্যাট ও নোটিফিকেশন সার্ভারে (WebSockets)
  • React, Vue বা Next.js এর ডেডিকেটেড ব্যাকএন্ড হিসেবে
  • মাইক্রোসার্ভিস আর্কিটেকচারে

🛠️ আধুনিক ওয়েব স্ট্যাক:

  • ফ্রেমওয়ার্ক: Express.js, Fastify
  • ডাটাবেস: MongoDB (Mongoose), PostgreSQL/MySQL (Prisma, Sequelize)
  • আর্কিটেকচার: MVC (Model-View-Controller)

⚙️ ২. নেটিভ `node:http` মডিউল কী এবং কীভাবে কাজ করে?

আমরা পরবর্তীতে যখন Express.js ফ্রেমওয়ার্ক শিখব, মনে রাখবেন—Express কিন্তু নিজে নিজে নেটওয়ার্ক হ্যান্ডেল করে না! সে তৈরি হয়েছে Node.js এর ভেতরে থাকা নেটিভ node:http মডিউলের ওপর ভর করে।

খুব সাধারণ একটি নেটিভ HTTP সার্ভার কোড:

import http from 'node:http';

// ১. সার্ভার তৈরি করা
const server = http.createServer((req, res) => {
  console.log(`ইউজারের রিকোয়েস্ট: ${req.method} ${req.url}`);

  // ২. স্ট্যাটাস কোড ও হেডার সেট করা
  res.statusCode = 200;
  res.setHeader('Content-Type', 'application/json; charset=utf-8');

  // ৩. ডাটা পাঠানো এবং কানেকশন শেষ করা
  const responseData = {
    message: 'স্বাগতম! আমাদের Node.js সার্ভার চালু আছে।',
    status: 'success'
  };

  res.end(JSON.stringify(responseData));
});

// ৩০০০ পোর্টে সার্ভার চালানো
server.listen(3000, () => {
  console.log('সার্ভার রানিং: http://localhost:3000');
});

📦 ৩. `req` (রিকোয়েস্ট) এবং `res` (রেসপন্স) এ কী থাকে?

📥 Request (`req`): ক্লায়েন্ট থেকে আসা তথ্য

  • req.method: ইউজার কী কাজ করতে চাচ্ছে? (GET ডাটা দেখতে, POST নতুন ডাটা পাঠাতে, DELETE মুছতে)।
  • req.url: ইউজার কোন লিংকে ঢুকছে? (যেমন /products?category=phone)।
  • req.headers: ইউজারের বাড়তি তথ্য (যেমন টোকেন authorization, ব্রাউজারের নাম ইত্যাদি)।

📤 Response (`res`): সার্ভার থেকে ফেরত পাঠানো তথ্য

  • res.statusCode: ৩ ডিজিটের স্ট্যাটাস কোড (২০০ মানে সফল, ২০১ মানে তৈরি হয়েছে, ৪০৪ মানে পেজ পাওয়া যায়নি, ৫০০ মানে সার্ভারে এরর)।
  • res.setHeader(): ব্রাউজারকে জানানো ডাটার ধরন কী (JSON নাকি HTML)।
  • res.end(data): ডাটা পাঠিয়ে কানেকশন ইতি টানা।
মূল কথা: আপনি যখন Express এ app.get('/users', (req, res) => res.json(...)) লিখবেন, তখন ব্যাকগ্রাউন্ডে ঠিক এই মেকানিজমটাই ঘটে। তাই নেটিভ কনসেপ্ট ক্লিয়ার থাকলে এক্সপ্রেসে কাজ করা পানির মত সহজ মনে হবে!
