ফেজ ০১ • টপিক ০১ ল্যাব

নেটিভ HTTP রিকোয়েস্ট ডিসপ্যাচার ও JSON রেসপন্ডার

হাতে-কলমে ওয়েব সার্ভারের মূল স্তম্ভগুলো তৈরি করুন: স্ট্যাটাস কোড সহ JSON রেসপন্স পাঠানো, URL থেকে কুয়েরি প্যারামিটার বের করা এবং রাউটিং হ্যান্ডেল করা।

📁 ল্যাব ফাইল স্ট্রাকচার: কীভাবে কাজ করবেন?

💻 ১. আপনার কোডিং ফাইল: index.js

এই ফাইলটিতে আপনি নিজে কোড লিখবেন! ভেতরে থাকা TODO সেকশনগুলো দেখে স্টেপ-বাই-স্টেপ ফাংশনগুলো পূরণ করবেন।

রান করার কমান্ড:

node index.js

🌟 ২. কমপ্লিট রেফারেন্স প্রজেক্ট: applied.js

এটি একটি সম্পূর্ণ তৈরি করা ও চালু থাকা প্রজেক্ট! এটি চালিয়ে আপনি দেখতে পারবেন একটি আসল ওয়েব সার্ভার কীভাবে কাজ করে এবং কোড বুঝতে পারবেন।

রান করার কমান্ড:

node applied.js

🎯 ল্যাবে যা যা তৈরি করবেন (in index.js)

টাস্ক ১: JSON রেসপন্স পাঠানোর ফাংশন (`sendJsonResponse`)

আমরা যখন ব্রাউজার বা মোবাইল অ্যাপে ডাটা পাঠাই, তখন JSON ফরম্যাটে পাঠাতে হয়। এই ফাংশনটি ৩টি কাজ করবে:

  • res.statusCode = statusCode; (যেমন: ২০০ বা ২০১ সেট করা)
  • res.setHeader('Content-Type', 'application/json'); (হেডার সেট করা)
  • res.end(JSON.stringify(data)); (অবজেক্টকে স্ট্রিং বানিয়ে ক্লায়েন্টকে পাঠানো)

টাস্ক ২: URL ও কুয়েরি প্যারামিটার আলাদা করা (`parseRequestUrl`)

ইউজার যখন /api/courses?category=backend&level=pro লিখে ভিজিট করে:

  • পাথনেম (Pathname) আলাদা করা: /api/courses
  • কুয়েরি অবজেক্ট তৈরি করা: { category: 'backend', level: 'pro' }
  • জাভাস্ক্রিপ্টের নেটিভ new URL(rawUrl, 'http://localhost') ব্যবহার করে এটি রিটার্ন করা।

টাস্ক ৩: সিম্পল রাউটার ক্লাস (`HttpDispatcher`)

এক্সপ্রেসের মতো নিজস্ব একটি রাউটার তৈরি করা:

  • get(path, handler): GET রিকোয়েস্টের জন্য রুট রেজিস্টার করা।
  • post(path, handler): POST রিকোয়েস্টের জন্য রুট রেজিস্টার করা।
  • dispatch(req, res): আসা রিকোয়েস্টের মেথড ও পাথ চেক করে সঠিক হ্যান্ডলার চালানো। যদি পাথ না মেলে, তবে সুন্দর একটি 404 JSON এরর পাঠানো: { status: 'fail', message: 'Route not found' }।
