# টপিক ০১ ল্যাব: সিম্পল নেটিভ HTTP সার্ভার ও JSON রেসপন্স

**টপিক ০১:** আধুনিক Node.js ওয়েব ল্যান্ডস্কেপ ও নেটিভ HTTP আর্কিটেকচার  
**ফেজ ০১:** Node.js ওয়েব ফান্ডামেন্টালস ও নেটিভ HTTP  

---

## 🎯 এই টপিকের লক্ষ্য:
টপিক ০১ এর মূল বিষয় হলো Node.js এর নিজস্ব `node:http` মডিউল দিয়ে একটি লাইভ ওয়েব সার্ভার চালু করা এবং JSON রেসপন্স পাঠানো।

---

## 📁 ফাইল পরিচিতি:

1. **`index.js` (আপনার কোডিং ফাইল):**  
   খুব ছোট ও সহজ দুটি ধাপ দেওয়া আছে। টিপস দেখে নিজে কোড লিখুন।
   ```bash
   node index.js
   ```

2. **`applied.js` (সম্পূর্ণ প্রজেক্ট রেফারেন্স):**  
   মাত্র ৩০-৩৫ লাইনের একটি পরিষ্কার ও কমপ্লিট সার্ভার কোড।
   ```bash
   node applied.js
   ```

---

## 🚀 যা যা করবেন:
- `http.createServer()` তৈরি করে `req.url` চেক করা।
- `/` এবং `/api/status` এ স্ট্যাটাস ২০০ সহ JSON পাঠানো।
- অন্য রুটে ৪০৪ (Not Found) পাঠানো।
- `server.listen(3000)` দিয়ে সার্ভার চালু করা।

কাজ শেষ হলে চ্যাটে বলুন: **"I am done"**!
