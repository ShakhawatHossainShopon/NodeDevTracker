URL Path, Query Parameters ও Headers পার্সার

আধুনিক WHATWG new URL() এবং req.headers দিয়ে যেকোনো ইনকামিং রিকোয়েস্টের পূর্ণাঙ্গ তথ্য রিড করার প্র্যাকটিস।

📁 ল্যাব ফাইল স্ট্রাকচার

💻 ১. আপনার ব্ল্যাঙ্ক কোডিং স্পেস: index.js

সম্পূর্ণ ফাঁকা ফাইল। স্ক্র্যাচ থেকে নিজে সার্ভার লিখে URL পার্সিং ও হেডার রিড করার কোড লিখুন।

node index.js

🌟 ২. রেফারেন্স প্রজেক্ট: applied.js

মাত্র ৪৫ লাইনের পরিষ্কার ও তৈরি রেফারেন্স কোড। কোডের কমেন্ট বাংলায় ও টার্মিনাল লগ সম্পূর্ণ খাঁটি ইংরেজিতে সাজানো।

node applied.js

🧪 টেস্ট করার নির্দেশনা

সার্ভার চালু করার পর ব্রাউজারে বা নতুন টার্মিনালে নিচের লিংকে রিকোয়েস্ট পাঠান:

http://localhost:3000/api/search?q=laptop&limit=5

টার্মিনালে মেথড, পাথ, কুয়েরি এবং হেডার তথ্য ইংরেজি লগে দেখতে পাবেন।
