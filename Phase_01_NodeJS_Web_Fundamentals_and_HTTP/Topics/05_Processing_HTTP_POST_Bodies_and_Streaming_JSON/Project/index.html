ফেজ ০১ • টপিক ০৫ ল্যাব

টার্মিনাল ক্লাসরুম — HTTP POST ও স্ট্রিমিং JSON

কোড না লিখেও টার্মিনালে লাইভ ট্রেস দেখে Node.js-এর ভেতরের স্ট্রিমিং ও বাফার আর্কিটেকচার শেখার ল্যাব।

🚀 টার্মিনালে ল্যাব চালু করুন

আপনার ১ম টার্মিনালে নিচের কমান্ডটি দিয়ে ইন্টারঅ্যাক্টিভ ক্লাসরুম চালু করুন:

node applied.js

সার্ভার চালু হলেই ৫টি প্রস্তুত টেস্ট কমান্ড দেখতে পাবেন।

🧪 ২য় টার্মিনালে টেস্ট কমান্ড চালিয়ে এক্সপ্লোর করুন

১. সঠিক JSON পাঠিয়ে ইউজার তৈরি (201 Created)
লক্ষ্য করুন কীভাবে Stream chunk রিসিভ হলো, বাফার জোড়া লাগল এবং 201 স্ট্যাটাস কোড গেল।
Invoke-RestMethod -Uri "http://localhost:3000/api/users" -Method Post -ContentType "application/json" -Body '{"name":"Rahim Ahmed", "email":"rahim@example.com"}'
২. তৈরি হওয়া সব ইউজার চেক করা (200 OK)
মেমোরিতে সংরক্ষিত ডাটা রিড করা।
Invoke-RestMethod -Uri "http://localhost:3000/api/users" -Method Get
৩. ভ্যালিডেশন এরর টেস্ট (400 Bad Request)
ইমেইল ছাড়া ডাটা পাঠালে টার্মিনালে ভ্যালিডেশন ফেইলের লাইভ এক্সপ্ল্যানেশন দেখুন।
Invoke-RestMethod -Uri "http://localhost:3000/api/users" -Method Post -ContentType "application/json" -Body '{"name":"Only Name Without Email"}'
৪. ভাঙা JSON পাঠিয়ে ক্র্যাশ গার্ড টেস্ট (400 Bad Request)
try...catch কীভাবে সিনট্যাক্স এরর হ্যান্ডেল করে সার্ভার সচল রাখে।
Invoke-RestMethod -Uri "http://localhost:3000/api/users" -Method Post -ContentType "application/json" -Body '{"name": "Broken JSON missing bracket'
