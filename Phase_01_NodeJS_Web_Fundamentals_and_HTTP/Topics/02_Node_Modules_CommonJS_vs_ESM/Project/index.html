প্র্যাকটিক্যালি দেখুন কীভাবে export default ফাইলে থাকা নাম ভুলে গিয়ে ইমপোর্টে আপনার দেওয়া যেকোনো নামেই চলে আসে (ঠিক যেমন MongoDB মডেল ও Redux এ ঘটে)!

📁 ল্যাব ফাইল স্ট্রাকচার

💻 ১. আপনার ব্ল্যাঙ্ক কোডিং স্পেস: index.js

সম্পূর্ণ ফাঁকা ফাইল। userService.js থেকে ডিফল্ট এক্সপোর্টটি ভিন্ন কোনো নামে এবং নেইমড এক্সপোর্টগুলো ব্র্যাকেটে এনে কনসোলে প্রিন্ট করুন।

node index.js

🌟 ২. রেফারেন্স প্রজেক্ট: applied.js

মাত্র ১৫-২০ লাইনের সম্পূর্ণ কোড। দেখুন কীভাবে User কে UserModel নামে ইমপোর্ট করেও নির্বিঘ্নে চালানো হয়েছে।

node applied.js

💡 মূল রহস্য: কোড প্রিভিউ

userService.js এ আমরা লিখেছি:

export default User; // ডিফল্ট (একটাই মান পাঠাচ্ছে)
export function validateEmail(...) { ... } // নেইমড

আর applied.js এ আমরা ইমপোর্ট করেছি:

// কোনো কার্লি ব্র্যাকেট নেই, নিজের নাম দিয়েছি 'UserModel'!
// আর কার্লি ব্র্যাকেটে { validateEmail } দিতেই হয়েছে কারণ ওটা Named!
import UserModel, { validateEmail } from './userService.js';

console.log(UserModel.name); // 'Tanvir Ahmed'
