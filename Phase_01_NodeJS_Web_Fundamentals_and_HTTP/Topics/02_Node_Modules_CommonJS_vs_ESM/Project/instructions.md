# টপিক ০২ ল্যাব: Default Export (ভিন্ন নাম) বনাম Named Export

**টপিক ০২:** Node.js মডিউল সিস্টেম: CommonJS বনাম ES Modules  
**ফেজ ০১:** Node.js ওয়েব ফান্ডামেন্টালস ও নেটিভ HTTP  

---

## 🎯 এই ল্যাবের মূল প্র্যাকটিস:
প্র্যাকটিক্যালি প্রমাণ করা যে:
1. `export default` ফাইলে একটাই থাকে এবং ইমপোর্ট করার সময় কোনো কার্লি ব্র্যাকেট ছাড়া **ইচ্ছামতো যেকোনো ভিন্ন নাম** (যেমন: `UserModel` বা `MyUser`) দিয়ে ইমপোর্ট করা যায়।
2. কিন্তু সাধারণ `export` (Named export) আনতে গেলে অবশ্যই কার্লি ব্র্যাকেট `{ }` এর ভেতর **হুবহু একই নাম** দিতে হয়।

---

## 📁 ফাইল পরিচিতি:

1. **`userService.js`:**  
   এখানে `export default User` এবং দুটো Named Function (`validateEmail`, `formatRole`) এক্সপোর্ট করা আছে।

2. **`index.js` (আপনার ব্ল্যাঙ্ক কোডিং ফাইল):**  
   সম্পূর্ণ ফাঁকা ফাইল। আপনি নিজে `userService.js` থেকে ইমপোর্ট করে কনসোলে প্রিন্ট করে টেস্ট করুন।
   ```bash
   node index.js
   ```

3. **`applied.js` (সম্পূর্ণ প্রজেক্ট রেফারেন্স):**  
   মাত্র ১৫-২০ লাইনের কমপ্লিট প্রস্তুত কোড।
   ```bash
   node applied.js
   ```
