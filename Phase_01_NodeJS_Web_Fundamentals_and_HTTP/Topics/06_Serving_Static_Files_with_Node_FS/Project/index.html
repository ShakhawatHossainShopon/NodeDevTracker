ফেজ ০১ • টপিক ০৬ ল্যাব

নেটিভ স্ট্যাটিক ফাইল সার্ভার (HTML, CSS, JS)

MIME টাইপ রেজোলিউশন, ডিরেক্টরি ট্রাভার্সাল সিকিউরিটি এবং fs.createReadStream().pipe(res) দিয়ে ফাইল স্ট্রিমিং।

📁 ল্যাব ফাইল স্ট্রাকচার

💻 আপনার কোডিং স্পেস: index.js

আমরা একসাথে ধাপে ধাপে (Step-by-Step) এখানে স্ট্যাটিক ফাইল সার্ভার তৈরি করব।

node index.js

🌟 কমপ্লিট ক্লাসরুম ল্যাব: applied.js

সম্পূর্ণ তৈরি রেফারেন্স ফাইল। রান করে ব্রাউজারে গেলেই প্রতিটি অ্যাসেট লোডের লাইভ লগ দেখতে পাবেন।

node applied.js

🧪 টেস্ট করার উপায়

সার্ভার চালুর পর সরাসরি আপনার ওয়েব ব্রাউজারে নিচের লিংকে যান:

http://localhost:3000/

ব্রাউজার স্বয়ংক্রিয়ভাবে HTML-এর ভেতর থেকে /style.css এবং /app.js কল করবে এবং টার্মিনালে স্ট্রিমিং লগ দেখতে পাবেন।
