# টপিক ০৬ ল্যাব: নেটিভ স্ট্যাটিক ফাইল সার্ভার (HTML, CSS, JS)

**টপিক ০৬:** Serving Static Files (HTML, CSS, Images) with `node:fs`  
**ফেজ ০১:** Node.js Web Fundamentals (Phase 01-এর ফাইনাল টপিক!)  

---

## 🎯 ল্যাব কনসেপ্ট:
একটি ফুল-স্ট্যাক ওয়েব সার্ভারে শুধু JSON API বানালেই চলে না, ব্রাউজারে HTML, CSS, JavaScript এবং ইমেজ ফাইল সফলভাবে সার্ভ করতে হয়।
1. **MIME Types ম্যাপিং:** এক্সটেনশন (`.html`, `.css`, `.js`) অনুযায়ী সঠিক `Content-Type` হেডার সেট করা।
2. **Directory Traversal সিকিউরিটি:** `../../` দিয়ে হ্যাকাররা যেন সিস্টেমের বাইরের ফাইল রিড করতে না পারে তা ব্লক করা।
3. **হাই-পারফরম্যান্স স্ট্রিমিং:** পুরো ফাইল মেমোরিতে লোড না করে `fs.createReadStream().pipe(res)` দিয়ে সরাসরি ক্লায়েন্টে পাইপ করা।

---

## 📁 ল্যাব ফাইল স্ট্রাকচার:
* `public/index.html` — ল্যান্ডিং পেজ
* `public/style.css` — স্টাইলশিট
* `public/app.js` — ক্লায়েন্ট-সাইড জাভাস্ক্রিপ্ট
* `applied.js` — সম্পূর্ণ রেফারেন্স কোড ও ইন্টারঅ্যাক্টিভ ক্লাসরুম
* `index.js` — স্টেপ-বাই-স্টেপ কোডিং স্পেস

---

## 🧪 টেস্ট করার উপায়:
১. টার্মিনালে সার্ভার চালান:
```bash
node applied.js
```
২. ব্রাউজারে যেকোনো ট্যাবে গিয়ে ওপেন করুন:
```text
http://localhost:3000/
```
ব্রাউজারে সুন্দর স্টাইল করা পেজ দেখতে পাবেন এবং টার্মিনালে লক্ষ্য করবেন কীভাবে ব্রাউজার প্রথমে `index.html`, তারপর `style.css` এবং এরপর `app.js` রিকোয়েস্ট করে একে একে স্ট্যাটিক অ্যাসেটগুলো লোড করল!
