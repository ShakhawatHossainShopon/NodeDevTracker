# টপিক ০৩ ল্যাব: HTTP Request/Response লাইফসাইকেল লগার

**টপিক ০৩:** Native HTTP Server (`node:http`) & Request/Response Life Cycle  
**ফেজ ০১:** Node.js ওয়েব ফান্ডামেন্টালস ও নেটিভ HTTP  

---

## 🎯 এই ল্যাবের মূল প্র্যাকটিস:
একটি HTTP সার্ভারে রিকোয়েস্ট শুরু থেকে রেসপন্স শেষ হওয়া পর্যন্ত লাইফসাইকেল ট্র্যাক করা:
1. রিকোয়েস্ট আসার সময় শুরুর টাইম (`Date.now()`) রেকর্ড করা।
2. `res.on('finish', () => ...)` লাইফসাইকেল ইভেন্ট ব্যবহার করে রেসপন্স শেষ হওয়ার মোট সময় (Latency ms) হিসেব করে কনসোলে লগ দেওয়া।

## 📁 ফাইল পরিচিতি:

1. **`index.js` (আপনার ব্ল্যাঙ্ক কোডিং ফাইল):**  
   সম্পূর্ণ ফাঁকা ফাইল। আপনি নিজে লাইফসাইকেল ট্র্যাকিং সার্ভার কোড লিখুন।
   ```bash
   node index.js
   ```

2. **`applied.js` (সম্পূর্ণ প্রজেক্ট রেফারেন্স):**  
   মাত্র ৩০-৩৫ লাইনের পরিচ্ছন্ন ও প্রস্তুত কোড।
   ```bash
   node applied.js
   ```
