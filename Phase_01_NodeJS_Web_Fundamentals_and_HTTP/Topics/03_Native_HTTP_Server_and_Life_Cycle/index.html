ফেজ ০১: Node.js ওয়েব ফান্ডামেন্টালস টপিক ০৩

নেটিভ HTTP সার্ভার ও Request/Response লাইফসাইকেল

সহজ বাংলায় জানুন: ইউজার যখন ব্রাউজারে এন্টার চাপে, তখন থেকে শুরু করে রেসপন্স ফেরত যাওয়া পর্যন্ত ব্যাকগ্রাউন্ডে ঠিক কোন কোন ধাপে কাজগুলো ঘটে।

🔄 ১. একটি HTTP রিকোয়েস্টের জীবনচক্র (Life Cycle)

যখন কোনো ইউজার আপনার সার্ভারের ইউআরএলে (যেমন http://localhost:3000/profile) ভিজিট করে, একটি পূর্ণাঙ্গ লাইফসাইকেল শুরু হয়:

ধাপ ১: ক্লায়েন্ট থেকে রিকোয়েস্ট আসে (TCP Socket)

ব্রাউজার সার্ভারের ৩০০০ পোর্টে একটি কানেকশন ওপেন করে বাইনারি ডাটা পাঠানো শুরু করে।

ধাপ ২: Node.js এর HTTP পার্সার সক্রিয় হয়

বাইনারি ডাটা থেকে মেথড (GET, POST), ইউআরএল ও হেডার পড়ে Node.js একটি req অবজেক্ট তৈরি করে।

ধাপ ৩: আপনার কোড রেসপন্স তৈরি করে

আপনার লেখা ফাংশনে স্ট্যাটাস কোড (200, 404) ও হেডার সেট করা হয় এবং res.end(data) কল করা হয়।

ধাপ ৪: `res.on('finish')` - রেসপন্স সম্পন্ন হওয়া

যখন সব ডাটা ব্রাউজারের উদ্দেশ্যে পাঠিয়ে দেওয়া শেষ হয়, তখন finish ইভেন্ট ফায়ার করে। আমরা এই ইভেন্ট ব্যবহার করে সার্ভারের রেসপন্স টাইম (Latency) মাপতে পারি!

⏱️ ২. সার্ভারের গতি বা Latency মাপা কেন দরকার?

প্রোডাকশন লেভেলের ব্যাকএন্ডে সবচেয়ে গুরুত্বপূর্ণ বিষয়গুলোর একটি হলো—একটি রিকোয়েস্ট হ্যান্ডেল করতে সার্ভার কত মিলিসেকেন্ড সময় নিল?

আমরা রিকোয়েস্ট আসার সময় শুরুর টাইম (Date.now()) রেকর্ড করব এবং যখন রেসপন্স পাঠানো শেষ হবে (res.on('finish')), তখন বিয়োগ করে বের করব রিকোয়েস্টটি সম্পন্ন হতে কত মিলিসেকেন্ড লাগল: 

import http from 'node:http';

const server = http.createServer((req, res) => {
  const startTime = Date.now(); // রিকোয়েস্ট আসার সময়

  // রেসপন্স শেষ হলে এই ইভেন্টটি অটোমেটিক চলবে
  res.on('finish', () => {
    const duration = Date.now() - startTime;
    console.log(`[${req.method}] ${req.url} -> Status: ${res.statusCode} | Duration: ${duration}ms`);
  });

  res.statusCode = 200;
  res.setHeader('Content-Type', 'application/json');
  res.end(JSON.stringify({ status: 'ok', message: 'Hello World' }));
});

server.listen(3000);

টপিক ০৩ ল্যাব প্রজেক্ট দেখতে প্রস্তুত?

ল্যাব ফোল্ডারে গিয়ে লাইফসাইকেল লগার ও টাইমিং সার্ভার প্রজেক্টটি লক্ষ্য করুন।
