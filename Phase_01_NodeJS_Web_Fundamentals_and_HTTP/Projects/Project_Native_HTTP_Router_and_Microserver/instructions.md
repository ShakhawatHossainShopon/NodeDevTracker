# ফেজ ০১ ক্যাপস্টোন প্রজেক্ট: Native HTTP Micro-Server & Web Router

**ফেজ ০১:** Node.js Web Fundamentals & Native HTTP (ক্যাপস্টোন টেস্ট ল্যাব)  

---

## 🎯 আপনার মিশন (Hands-On Capstone Exam):
এই ক্যাপস্টোন প্রজেক্টের কোনো রেডিমেড কোড নেই। টপিক ০১ থেকে ০৬ পর্যন্ত আপনি যা যা শিখেছেন, তার ভিত্তিতে আপনি নিজেই `index.js`-এ স্ক্র্যাচ থেকে পুরো সার্ভারটি তৈরি করবেন। আমি কেবল একজন মেন্টর ও গাইড হিসেবে আপনাকে স্পেসিফিকেশন এবং রোডম্যাপ দেব।

---

## 🏛️ আর্কিটেকচারাল রিকোয়ারমেন্টস (যা যা বানাতে হবে):

1. **বেস সার্ভার ও ল্যাটেন্সি লগার:**
   - ৩০০০ পোর্টে `http.createServer()` চালু করা।
   - `res.on('finish')` দিয়ে প্রতি রিকোয়েস্টের এক্সিকিউশন টাইম (ল্যাটেন্সি ms) টার্মিনালে লগ করা।

2. **এপিআই এন্ডপয়েন্ট ১ — হেলথ স্ট্যাটাস:**
   - `GET /api/status`
   - রেসপন্স: 200 OK সহ সার্ভারের আপটাইম (`process.uptime()`), মেমোরি এবং টাইমস্ট্যাম্পের JSON।

3. **এপিআই এন্ডপয়েন্ট ২ — ইউজার তালিকা:**
   - `GET /api/users`
   - রেসপন্স: 200 OK সহ মেমোরিতে থাকা ইউজারদের অ্যারে।

4. **এপিআই এন্ডপয়েন্ট ৩ — ডাইনামিক রুট প্যারামিটার:**
   - `GET /api/users/:id` (যেমন: `/api/users/1`)
   - রেগুলার এক্সপ্রেশন বা পাথ স্প্লিট করে আইডি বের করা।
   - আইডি পাওয়া গেলে 200 OK, না পাওয়া গেলে 404 Not Found।

5. **এপিআই এন্ডপয়েন্ট ৪ — কুয়েরি স্ট্রিং সার্চ:**
   - `GET /api/search?q=...&limit=...`
   - `new URL()` এর `searchParams` ব্যবহার করে নাম বা রোলে ফিল্টার করা।

6. **এপিআই এন্ডপয়েন্ট ৫ — স্ট্রিমিং JSON বডি দিয়ে ইউজার তৈরি:**
   - `POST /api/users`
   - `req.on('data')` এবং `req.on('end')` দিয়ে বডি সংগ্রহ করা, `try...catch` দিয়ে `JSON.parse` করা।
   - `name` ও `email` ভ্যালিডেশন করে 201 Created রেসপন্স দেওয়া।

7. **স্ট্যাটিক ফাইল সার্ভার ফলব্যাক:**
   - রুট বা যেকোনো স্ট্যাটিক ফাইলের জন্য `public/` ফোল্ডারের ফাইলসমূহ MIME Type অনুযায়ী `fs.createReadStream().pipe(res)` দিয়ে সার্ভ করা।
   - ডিরেক্টরি ট্রাভার্সাল গার্ড (`startsWith(PUBLIC_DIR)`) রাখা।
