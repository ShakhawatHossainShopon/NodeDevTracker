🏠 মাস্টার ট্র্যাকার ⬅️ টপিক ০৬ স্টাডি গাইড
ফেজ ০১ ফাইনাল ক্যাপস্টোন প্রজেক্ট (হ্যান্ডস-অন টেস্ট)

Native HTTP Micro-Server & Web Router

কোনো এক্সটার্নাল প্যাকেজ বা ফ্রেমওয়ার্ক ছাড়া পিওর Node.js দিয়ে একটি ফুল-ফিচার্ড মাইক্রো-সার্ভার আর্কিটেক্ট করার চূড়ান্ত পরীক্ষা।

📝 ক্যাপস্টোন টেস্ট নিয়মাবলী:
এই ক্যাপস্টোন প্রজেক্টের কোনো রেডিমেড কোড নেই। টপিক ০১-০৬ পর্যন্ত যা শিখেছেন, তার ভিত্তিতে আপনি নিজেই index.js-এ স্ক্র্যাচ থেকে পুরো সার্ভারটি তৈরি করবেন। আমি একজন মেন্টর ও গাইড হিসেবে আপনাকে ধাপে ধাপে কী করতে হবে তা বলব এবং সহায়তা করব।

🎯 ক্যাপস্টোনের এপিআই এন্ডপয়েন্ট সমূহ

মেথড এন্ডপয়েন্ট কাজ ও প্রযুক্তি
GET /api/status সার্ভার হেলথ, আপটাইম ও মেমোরি কনজাম্পশন (process.uptime, heapUsed)
GET /api/users মেমোরিতে থাকা সব ইউজারের তালিকা রিটার্ন করা (200 OK)
GET /api/users/:id ডাইনামিক রুট প্যারামিটার ম্যাচিং (Regex) দিয়ে নির্দিষ্ট ইউজার রিটার্ন বা 404
GET /api/search?q=...&limit=... WHATWG searchParams দিয়ে ফিল্টারিং এবং স্লাইস করে লিমিটেড ডাটা প্রদান
POST /api/users ইনকামিং বাফার চাঙ্ক স্ট্রিমিং ও পার্সিং, ফিল্ড ভ্যালিডেশন এবং 201 Created রেসপন্স
GET /* (Static Files) পাবলিক ফোল্ডারের ফাইলসমূহ (HTML/CSS/JS) সিকিউর পাথ চেক করে ব্রাউজারে পাইপ করা

📁 ফাইল পরিচিতি

index.js: সম্পূর্ণ ব্ল্যাঙ্ক ফাইল। এখানে আপনি নিজে কোড লিখবেন।

public/: ক্লায়েন্ট ড্যাশবোর্ড রাখা আছে (HTML, CSS, JS), যা সার্ভার ঠিকমতো চললে ব্রাউজারে দেখা যাবে এবং বাটন দিয়ে টেস্ট করা যাবে।
