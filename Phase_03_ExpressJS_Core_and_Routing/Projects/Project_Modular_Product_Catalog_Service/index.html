ফেজ ০৩ ক্যাপস্টোন প্রজেক্ট: Modular RESTful Product Catalog Service

প্রোডাকশন-গ্রেড Express.js দিয়ে পূর্ণাঙ্গ মডুলার প্রোডাক্ট ও ক্যাটাগরি ক্যাটালগ API সার্ভিস।

🎯 প্রজেক্টের উদ্দেশ্য ও সিস্টেম আর্কিটেকচার

এই ক্যাপস্টোন প্রজেক্টে আপনি express.Router() ব্যবহার করে একটি মডুলার, ইন্ডাস্ট্রি-লেভেল প্রোডাক্ট ক্যাটালগ মাইক্রোসার্ভিস আর্কিটেক্ট করবেন। এটি:

  1. আলাদা আলাদা রিসোর্স রাউটার (products.router.js, categories.router.js) এর মাধ্যমে সম্পূর্ণ ডিকাপল্ড থাকবে।
  2. নেস্টেড রাউটিং সাপোর্ট করবে (যেমন /api/v1/categories/:categoryId/products)।
  3. কুয়েরি স্ট্রিং ভিত্তিক ফিল্টারিং (যেমন ?minPrice=100&maxPrice=500&sort=asc) এবং পেজিনেশন হ্যান্ডল করবে।
  4. সেন্ট্রালাইজড এনভায়রনমেন্ট কনফিগারেশন সাপোর্ট করবে।
🔒 ক্যাপস্টোন বাউন্ডারি রুল: এই প্রজেক্টের কোড আপনি নিজে পিসিতে বসে লিখবেন। এই ফাইলটিতে শুধুমাত্র আর্কিটেকচার, স্পেসিফিকেশন ও টেস্ট কেস নির্দেশিকা দেওয়া হয়েছে।

📋 প্রজেক্ট স্পেসিফিকেশন ও এন্ডপয়েন্টসমূহ

মেথড ও পাথ ইনপুট হেডার/বডি প্রত্যাশিত ফলাফল
GET /api/v1/products ?category=electronics&page=1 ফিল্টার্ড ও প্যাজিনেটেড প্রোডাক্ট লিস্ট রিটার্ন করবে।
POST /api/v1/products JSON Body: { name, price, categoryId } স্ট্যাটাস ২০১ সহ নতুন প্রোডাক্ট অবজেক্ট তৈরি করবে।
GET /api/v1/categories/:id/products Route Param: id নির্দিষ্ট ক্যাটাগরির সমস্ত প্রোডাক্ট রিটার্ন করবে।
