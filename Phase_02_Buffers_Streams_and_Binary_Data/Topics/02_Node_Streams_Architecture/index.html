Node Streams আর্কিটেকচার — Readable, Writable, Duplex ও Transform

মেমোরি ওভারফ্লো ছাড়া গিগাবাইট সাইজের ডাটা ছোট ছোট চাঙ্কে প্রসেস করার ফান্ডামেন্টাল স্ট্রিম আর্কিটেকচার।

১. স্ট্রিম (Stream) কী এবং কেন এটি ব্যাকএন্ডের প্রাণ?

ওয়েব ব্যাকএন্ডে যখন কোনো ইউজার ৫০০ মেগাবাইট বা ২ গিগাবাইটের একটি ফাইল আপলোড বা ডাউনলোড করে, তখন সেই ফাইলটি সম্পূর্ণ মেমোরিতে (RAM) লোড করা অত্যন্ত বিপজ্জনক। ৫ জন ইউজার একসাথে রিকোয়েস্ট পাঠালে সার্ভার JavaScript heap out of memory এরোরে ক্র্যাশ করবে।

স্ট্রিম (Streams) হলো সিকোয়েনশিয়াল ডাটা রিড বা রাইট করার একটি প্রক্রিয়া যা ডাটাকে সম্পূর্ণ মেমোরিতে না এনে ছোট ছোট খণ্ড বা চাঙ্ক (Chunk) আকারে প্রসেস করে।

💡 বাস্তব উদাহরণ: নেটফ্লিক্স বা ইউটিউবে মুভি দেখার সময় পুরো ২ ঘণ্টার সিনেমা আগে ডাউনলোড হয় না। কয়েক সেকেন্ডের বাফার লোড হতে হতেই প্লে শুরু হয় — এটাই স্ট্রিমিং!

২. Node.js-এ স্ট্রিমের ৪টি মৌলিক প্রকারভেদ

স্ট্রিম টাইপ কাজের ধরন Node.js রিয়েল এক্সাম্পল
Readable যেখান থেকে ডাটা ক্রমান্বয়ে রিড করা যায়। fs.createReadStream(), HTTP req
Writable যেখানে ক্রমান্বয়ে ডাটা রাইট করা যায়। fs.createWriteStream(), HTTP res
Duplex একই সাথে রিড ও রাইট দুটিই করা যায় (স্বাধীন চ্যানেল)। TCP net.Socket
Transform ডাটা রিড করে পরিবর্তন (মুডিফাই/এনক্রিপ্ট) করে আউটপুট দেয়। zlib.createGzip(), crypto.createCipheriv()

৩. Readable স্ট্রিমের মোড: Flowing বনাম Paused

Readable স্ট্রিম দুটি মোডে কাজ করতে পারে:

  • Paused Mode (ডিফল্ট): স্ট্রিম নিজে থেকে ডাটা পাঠায় না। stream.read() ডেকে অথবা readable ইভেন্ট শুনে ডাটা টানতে হয়।
  • Flowing Mode: ডাটা প্রস্তুত হওয়ামাত্র স্বয়ংক্রিয়ভাবে নির্গত হয়। stream.on('data', chunk => {}) লিসেনার যোগ করলে স্ট্রিম ফ্লোয়িং মোডে চলে যায়।

কোড উদাহরণ: মেমোরি-দক্ষ ফাইল কপি

import fs from 'node:fs';

const readable = fs.createReadStream('input.log', { highWaterMark: 64 * 1024 });
const writable = fs.createWriteStream('output.log');

readable.on('data', (chunk) => {
  console.log('Received chunk size:', chunk.length, 'bytes');
  writable.write(chunk);
});

readable.on('end', () => {
  writable.end();
  console.log('Streaming file copy completed!');
});

৪. কাস্টম Transform স্ট্রিম তৈরি করা

ওয়েব ব্যাকএন্ডে লগ স্যানিটাইজ করা, ডাটা হ্যাশ করা বা অন-দ্য-ফ্লাই টেক্সট রূপান্তর করতে Transform ক্লাস এক্সটেন্ড করা হয়:

import { Transform } from 'node:stream';

class UpperCaseTransform extends Transform {
  _transform(chunk, encoding, callback) {
    const uppercased = chunk.toString().toUpperCase();
    this.push(uppercased);
    callback();
  }
}

const upper = new UpperCaseTransform();
process.stdin.pipe(upper).pipe(process.stdout);
