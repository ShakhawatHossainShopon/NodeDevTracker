হাই-পারফরম্যান্স CSV/JSON ডাটা স্ট্রিমিং ও মেমোরি অপটিমাইজেশন

লক্ষ লক্ষ রেকর্ড এক্সপোর্ট করার সময় র‍্যামের ব্যবহার ৫০ মেগাবাইটের নিচে সীমাবদ্ধ রাখার প্রোডাকশন কৌশল।

১. সাধারণ ভুল: বিশাল অ্যারে মেমোরিতে লোড করে রেসপন্স দেওয়া

ডাটাবেস থেকে ১,০০,০০০ রেকর্ড ফেচ করে res.end(JSON.stringify(records)) দিলে তিনটি মারাত্মক ঘটনা ঘটে:

  1. ১ লক্ষ অবজেক্টের জন্য র‍্যামে প্রায় ৫০০ মেগাবাইট হিপ মেমোরি তাৎক্ষণিক দখল হয়।
  2. JSON.stringify() সিঙ্ক্রোনাস হওয়ার কারণে ৩-৪ সেকেন্ড ইভেন্ট লুপ সম্পূর্ণ ফ্রিজ থাকে। অন্য কোনো ইউজারের রিকোয়েস্ট সার্ভ হতে পারে না!
  3. একসাথে একাধিক ইউজার এক্সপোর্ট ক্লিক করলে JavaScript heap out of memory এরোরে সার্ভার ক্র্যাশ করে।

২. প্রোডাকশন সমাধান: অ্যাসিঙ্ক জেনারেটর ও NDJSON স্ট্রিমিং

অ্যারে হিসেবে না পাঠিয়ে প্রতিটি রেকর্ডকে নিউলাইন-ডিলিমিটেড JSON (NDJSON) বা CSV লাইন হিসেবে অন-দ্য-ফ্লাই তৈরি করে সরাসরি রেসপন্স স্ট্রিমে পাইপ করা হয়:

import http from 'node:http';
import { Readable } from 'node:stream';

async function* fetchAndYieldRecords(total) {
  for (let i = 1; i <= total; i++) {
    const record = { id: i, customer: 'User_' + i, amount: (i * 12.5).toFixed(2), status: 'PAID' };
    yield JSON.stringify(record) + '\\n';
  }
}

const server = http.createServer((req, res) => {
  if (req.url === '/export-ndjson') {
    res.writeHead(200, {
      'Content-Type': 'application/x-ndjson',
      'Transfer-Encoding': 'chunked'
    });

    Readable.from(fetchAndYieldRecords(100000)).pipe(res);
  }
});

server.listen(3000);
