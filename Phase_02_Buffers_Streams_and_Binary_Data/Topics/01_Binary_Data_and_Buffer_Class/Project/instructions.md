# টপিক ০১ ল্যাব: বাইনারি ডাটা হ্যান্ডলিং ও Node.js Buffer ক্লাস

**টপিক ০১:** ওয়েব ব্যাকএন্ডে বাইনারি ডাটা ও Node.js `Buffer` ক্লাস  
**ফেজ ০২:** বাফার, স্ট্রিম ও ওয়েব অ্যাপ্লিকেশনে বাইনারি ডাটা  

---

## 🎯 এই ল্যাবের লক্ষ্য:
ওয়েব ব্যাকএন্ড ডেভেলপমেন্টে শুধু প্লেইন টেক্সট বা JSON নিয়ে কাজ করা হয় না; ফাইল আপলোড, ইমেজ/ভিডিও স্ট্রিমিং, ক্রিপ্টোগ্রাফিক টোকেন এবং HTTP হেডার এনকোডিংয়ে সরাসরি **বাইনারি ডাটা (Raw Bytes)** নিয়ে কাজ করতে হয়। 

এই ল্যাবে আমরা একটি **Binary-Aware Web Server** তৈরি করব যা:
1. স্ট্রিং এবং মাল্টি-বাইট অক্ষরের বাইট-লেংথ (Byte Length) এবং হেক্সাডেসিমেল/বেইজ৬৪ এনকোডিং বিশ্লেষণ করবে (`/api/buffer-inspect`)।
2. ক্লায়েন্ট থেকে আসা HTTP `Authorization: Basic <base64>` হেডার ডিকোড করে ইউজারনেম ও পাসওয়ার্ড বের করবে (`/api/auth-decode`)।
3. মেমোরিতে থাকা র বাইনারি বাফার সরাসরি HTTP দিয়ে ব্রাউজারে রেন্ডারযোগ্য ১x১ পিক্সেল ট্রান্সপারেন্ট PNG ইমেজ হিসেবে পাঠাবে (`/api/pixel.png`)।

## 📁 ফাইল পরিচিতি:

1. **`index.js` (আপনার হ্যান্ডস-অন ফাইল):**  
   আমরা ধাপে ধাপে ইন্টারেক্টিভভাবে এই ফাইলে কোড লিখব।
   ```bash
   node --watch index.js
   ```

2. **`applied.js` (কমপ্লিট রেফারেন্স সল্যুশন):**  
   রেফারেন্স কোড দেখতে বা সরাসরি রান করতে:
   ```bash
   node applied.js
   ```

## 🚀 ল্যাব চ্যালেঞ্জসমূহ (৩টি ধাপ):

- **ধাপ ১: বাফার ইন্সপেক্টর তৈরি (`/api/buffer-inspect`):**
  - কুয়েরি প্যারামিটার `?text=...` গ্রহণ করা।
  - `Buffer.from(text, 'utf-8')` তৈরি করা।
  - `text.length` বনাম `Buffer.byteLength(text, 'utf-8')` এর পার্থক্য দেখানো (বিশেষ করে বাংলা ও ইমোজির ক্ষেত্রে)।
  - হেক্স (`buf.toString('hex')`) ও বেইজ৬৪ (`buf.toString('base64')`) ফরম্যাটে JSON রেসপন্স পাঠানো।

- **ধাপ ২: HTTP Basic Auth হেডার ডিকোডার (`/api/auth-decode`):**
  - `req.headers['authorization']` থেকে `Basic <base64>` এক্সট্র্যাক্ট করা।
  - `Buffer.from(base64Str, 'base64').toString('utf-8')` দিয়ে ইউজারনেম ও পাসওয়ার্ড ডিকোড করা।
  - সফল হলে ইউজার ক্রেডেনশিয়াল JSON আকারে রিটার্ন করা।

- **ধাপ ৩: বাইনারি PNG ইমেজ সার্ভ করা (`/api/pixel.png`):**
  - মেমোরিতে একটি ১x১ ট্রান্সপারেন্ট PNG এর Base64 স্ট্রিংকে বাফারে রূপান্তর করা।
  - সঠিক হেডার `Content-Type: image/png` এবং `Content-Length: buffer.length` সেট করে সরাসরি বাফারটি ক্লায়েন্টে পাঠানো (`res.end(pixelBuffer)`).

সার্ভার চালু করার পর ব্রাউজার বা কার্ল (cURL) দিয়ে টেস্ট করুন:

2. `http://localhost:3000/api/pixel.png`

   ```powershell
   curl -H "Authorization: Basic YWRtaW46c2VjcmV0MTIz" http://localhost:3000/api/auth-decode
   ```
