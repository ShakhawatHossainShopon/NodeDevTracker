ল্যাব ০১: বাইনারি ডাটা হ্যান্ডলিং ও Node.js Buffer ক্লাস

বাফার এনকোডিং, মাল্টিবাইট ক্যারেক্টার সাইজ গণনা, বেসিক অথ ডিকোড এবং বাইনারি ইমেজ সরাসরি HTTP-তে সার্ভ করার প্র্যাকটিক্যাল ল্যাব।

🎯 ল্যাবের আর্কিটেকচার ও এন্ডপয়েন্টসমূহ

এই ল্যাবে আমরা একটি পূর্ণাঙ্গ বাইনারি-সচেতন ওয়েব সার্ভার আর্কিটেক্ট করব। এতে ৩টি গুরুত্বপূর্ণ এন্ডপয়েন্ট থাকবে:

GET /api/buffer-inspect?text=...

টেক্সটের স্ট্রিং লেংথ বনাম আসল বাইট সাইজ এবং হেক্স ও বেইজ৬৪ রিপ্রেজেন্টেশন রিটার্ন করে।

GET /api/auth-decode

ইনকামিং HTTP Authorization: Basic <base64> হেডারকে বাফার মেমোরির মাধ্যমে ডিকোড করে।

GET /api/pixel.png

মেমোরিতে থাকা র বাইনারি বাফার (১x১ ট্রান্সপারেন্ট PNG) সরাসরি image/png হেডারে সার্ভ করে।

🛠️ ধাপে ধাপে বাস্তবায়ন (Step-by-Step Implementation)

ধাপ ১

নেটিভ সার্ভার সেটআপ ও বাফার ইন্সপেক্টর এন্ডপয়েন্ট

node:http এবং node:buffer ইমপোর্ট করে সার্ভার চালু করব এবং /api/buffer-inspect এন্ডপয়েন্ট হ্যান্ডল করব। এটি Buffer.byteLength() বনাম str.length এর স্পষ্ট তুলনা আউটপুট দেবে।

টেস্ট কুয়েরি: http://localhost:3000/api/buffer-inspect?text=Node.js%20বাংলা

ধাপ ২

HTTP Basic Authentication হেডার ডিকোডার

req.headers['authorization'] থেকে Base64 ক্রেডেনশিয়াল এক্সট্র্যাক্ট করে Buffer.from(base64, 'base64').toString('utf-8') মেথডে ডিকোড করে ইউজারনেম ও পাসওয়ার্ড পৃথক করা হবে। হেডার না থাকলে ৪০১ আনঅথোরাইজড রেসপন্স দেবে।

ধাপ ৩

বাইনারি ইমেজ বাফার সরাসরি সার্ভ করা

মেমোরিতে সংরক্ষিত ১x১ ট্রান্সপারেন্ট PNG বাফারকে Content-Type: image/png এবং Content-Length: buffer.length সহ res.end(PIXEL_BUFFER) দিয়ে সরাসরি ক্লায়েন্টে স্ট্রিম করা হবে।

🧪 কীভাবে রান এবং টেস্ট করবেন

আপনার টার্মিনালে এই ফোল্ডারে এসে ওয়াচ মোডে সার্ভার চালু করুন:

node --watch index.js

টেস্টিং কমান্ডসমূহ (PowerShell বা ব্রাউজার):

# ১. বাফার ইন্সপেক্টর টেস্ট:
curl "http://localhost:3000/api/buffer-inspect?text=Node.js%20বাংলা"

# ২. Basic Auth হেডার ডিকোডার টেস্ট:
curl -H "Authorization: Basic YWRtaW46c2VjcmV0MTIz" "http://localhost:3000/api/auth-decode"

# ৩. বাইনারি ইমেজ ফেচ টেস্ট:
curl -I "http://localhost:3000/api/pixel.png"
